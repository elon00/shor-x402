# THE CREATOR Governance

This repository is governed by the evidence-first principles of `elon00/magical-garbage`.

## Required status model

Use only: `PRODUCTION_READY`, `DEVELOPMENT_READY`, `RESEARCH`, `SIMULATION`, `EDUCATIONAL`, `ARCHIVE`, or `BLOCKED`.

## Non-negotiable rules

1. Never represent mocked, simulated, placeholder, or fabricated outputs as real execution.
2. Blockchain claims require verifiable network evidence.
3. Cryptographic claims require real algorithm/library verification and tests.
4. AI/quantum capabilities must be labeled according to what is actually executed.
5. Secrets, seed phrases, private keys, and credentials must never be committed.
6. Production readiness requires reproducible tests, security checks, and deployment evidence.
